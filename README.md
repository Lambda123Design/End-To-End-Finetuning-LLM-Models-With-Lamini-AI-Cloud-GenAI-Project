# End-To-End-Finetuning-LLM-Models-With-Lamini-AI-Cloud-GenAI-Project
This Repository contains my working files of "End To End Finetuning LLM Models With Lamini AI Cloud Project", an GenAI Project

(i) Leveraged Lamini to simplify fine-tuning of open-source LLMs.

(ii) Configured Lamini API integration and executed fine-tuning using a single LLM tune call, which automatically handled backend optimizations, including LoRA adaptation and quantization.

(iii) Customized hyperparameters such as learning rate, maximum training steps, and optimizer settings to optimize model performance for the specific dataset.

(iv) Evaluated and tested the fine-tuned model in Lamini’s interactive playground, enabling immediate feedback on generated responses.
